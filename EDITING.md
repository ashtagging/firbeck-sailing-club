# Editing the words on the website

This is a plain step-by-step guide for changing any of the text on the
Firbeck Sailing Club website — no coding knowledge, no GitHub account, and
nothing to install.

## One-off setup (Ashley does this once)

Ashley needs to invite you by email from the Netlify dashboard (Identity →
Invite users). You'll get an email — click the link in it and set a
password. That's the only account you need; it's separate from GitHub.

## How to change some text

1. Go to **`firbecksailingclub.com/admin`**.
2. Log in with the email and password from your invite.
3. You'll see one screen called **"Website Text"** with a labelled box for
   every sentence on the site — "Main heading", "Membership fee", "Footer
   email", and so on, grouped by the section of the page they're in (use
   the table below if you're not sure which box controls what).
4. Click into any box and change the wording. There are no tags, brackets
   or code to worry about — just type.
5. When you're happy, scroll up and click the green **Publish** button
   (top right).
6. That's it — the live website updates itself automatically, usually
   within a minute or two. Refresh the site to check.

If something looks wrong after publishing, the CMS keeps every previous
version — ask Ashley to help you roll back a change if needed; nothing is
ever really lost.

## What each box controls

| Section | Box | What it is |
|---|---|---|
| Header | Club name / Place name | The name and place shown at the very top of every page |
| Top of the page (hero) | Anniversary badge | The "50th Anniversary" badge |
| | Main heading | The big headline at the top |
| | Welcome statement | The line under the two top buttons |
| Reasons to join | Section heading | "Plenty of reasons to join us" |
| | The six reasons | Each has a **Title** (bold heading) and **Text** (the sentence under it) |
| When we sail | Small label / Heading / Paragraph | The navy box describing when members sail |
| Notice box | Kicker / Text | The "Coming in winter 2026" clubhouse notice |
| Racing panel | Small label / Heading / Paragraph | The "Racing, sort of" panel |
| Membership | Small label / Heading (the yearly fee) | "£30 a year for the whole family" |
| | Part-year note | The £10 part-year rate line |
| | Paragraph | The sentence explaining how to join |
| | The three steps to join | The numbered steps |
| | Download button text | The wording on the yellow download button |
| Find us | Small label / Heading / Paragraph | The venue section |
| Footer | Club name / Address / Founded note | The bottom of the page |
| | Contact email | The club's email — used in two places, kept in sync automatically |
| | Secretary name | The secretary's name at the bottom |

## Things not to change here

- **Bank details** aren't on the website at all — they're only inside the
  Word membership form, so there's nothing to edit for those.
- The **membership form file itself**, **photos**, and technical search-engine
  details aren't in this screen on purpose, so they can't be broken by
  accident. Ask Ashley if one of those needs updating (e.g. a new year's
  membership form).
- Don't add exclamation marks or change the tone too much — the club likes
  to keep things plain and warm, not "salesy".
